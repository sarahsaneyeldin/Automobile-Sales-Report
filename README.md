# Automobile Sales Performance Dashboard (Power BI)

This project is a comprehensive **Data Analysis** and **Business Intelligence (BI)** solution focused on tracking and analyzing sales performance for an automobile company. It showcases practical proficiency in Power BI, data modeling, and deriving actionable business insights.

---

## Project Goal
The primary objective was to design and deploy an **interactive Power BI Dashboard** that provides key stakeholders with timely insights into sales trends, regional effectiveness, and product performance to support **data-driven decision-making**.

## Key Features & Insights
* **KPI Tracking:** Monitoring critical KPIs such as Total Sales Revenue, Sales Volume, and Order Status using the provided dataset.
* **Regional Analysis:** Visualizing performance distribution across different regions/cities (e.g., NYC, Paris, San Francisco) to identify top markets and areas needing improvement.
* **Product Segmentation:** Deep-dive analysis of sales broken down by **Product Line** (e.g., Motorcycles, Trucks, Classic Cars) and **Deal Size** (Small, Medium, Large).

## Technology & Methodology
* **BI Tool:** **Power BI** (Used for Dashboard Development, Data Visualization).
* **Data Source:** Raw data was sourced from `Auto Sales data.csv`.
* **Data Preparation:** **Power Query** was utilized for initial data cleaning, transformation, and creating calculated columns to enrich the dataset.
* **Data Modeling:** Implemented a **Dimensional Data Modeling** approach (Star Schema principles) to establish clear relationships between sales facts and dimensional tables, ensuring optimal report performance.

## Deliverables
* **PBIX File:** The complete, ready-to-use Power BI report file (`automobileReportFinal.pbix`).
* **Data Source:** The raw dataset used for analysis (`Auto Sales data.csv`).
